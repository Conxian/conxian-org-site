Use the [Repository Status Matrix](/ecosystem/status/) for portfolio roles and source links. The former twelve-repository list mixed proposed projects and domains with existing repositories; it must not be used as deployment or capability evidence.

Bitcoin L1 is the canonical truth and finality root. The ecosystem serves external chains, networks, layers, and assets without introducing a native Conxian token. Public protocol contracts and developer references belong to `conxian.org`; managed APIs, deployment orchestration, enterprise SLAs, and compliance services belong to `conxian-labs.com`.

Registered adapters, implemented cryptographic primitives, live integrations, independent review, and production qualification are separate states. See [Capability and signing evidence](/docs/capability-evidence/). A repository URL or proposed service subdomain is not proof of an available runtime.
