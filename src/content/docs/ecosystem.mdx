## Domain Routing Architecture

All `conxian.org` domains serve technical distribution, developer documentation, and public cryptographic status feeds. Corporate sales, client billing, and legal operations are routed strictly to `conxian-labs.com`.

```

                    |        ORGANIZATION ROUTER        |
                    +-----------------+-----------------+

            +-------------------------+-------------------------+
            |                                                   |
            v                                                   v
  [ conxian.org Protocol ]                           [ conxian-labs.com Corp ]
  ├── nexus.conxian.org                              ├── bos.conxian-labs.com
  ├── gateway.conxian.org                            └── www.conxian-labs.com
  ├── sdk.conxian.org
  ├── platform.conxian.org

```
