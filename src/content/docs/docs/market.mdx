## Overview

`conxian_market` provides real-time auditability and zero-knowledge status feeds for financial regulators and enterprise auditors.

* **Target Subdomain:** `market.conxian.org`
* **Zero-Knowledge Proofs:** Verification of collateral solvency and hardware attestation without exposing private client account data.
* **Status Endpoints:** Real-time JSON status streams for Bitcoin L1 anchor verification.
