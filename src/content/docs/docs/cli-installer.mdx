## Overview

The `conxian-cli` utility provides an automated, pre-flight environment and hardware parameter validator for enterprise clients deploying Conxian stateless container workloads.

Before spinning up container instances, `conxian-cli` verifies host CPU flags, Linux kernel lockdown settings, hugepages allocation, Nitro/SGX device drivers, and network RPC endpoints.

---

## Pre-Flight Check Commands

```bash
# Execute full pre-flight hardware enclave and environment check
conxian-cli preflight --config /etc/conxian/.env --enclave-check

# Generate Hardware Enclave Attestation Report
conxian-cli enclave attest --output /var/run/enclave/attestation.bin

# Verify ISO 20022 XML Gateway endpoints
conxian-cli gateway verify-schemas --schema-dir /opt/conxian/schemas/iso20022/
```
