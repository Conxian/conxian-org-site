## Overview

`conxian-gateway` serves as the high-throughput bridge connecting legacy interbank messaging systems (SWIFT / FedNow / TIPS) to Bitcoin L1/L3 settlement primitives.

* **Target Subdomain:** `gateway.conxian.org`
* **Supported Message Formats:** `pacs.008.001.10` (Financial Institutional Customer Credit Transfer), `pacs.009` (Financial Institution Credit Transfer), `camt.053` (Bank-to-Customer Statement).
* **Callback Architecture:** OData v4 JSON query callback interface for automated enterprise core banking reconciliation.

## Technical Specifications

### ISO 20022 XML Normalization Pipeline

```
 +-------------------------+      +-------------------------+      +-------------------------+
 | Incoming ISO 20022 XML  | ---> |   conxian-gateway XML   | ---> |   OData v4 Normalized   |
 | (pacs.008 Payment Wire) |      | Parser & Security Check |      | JSON Settlement Payload |
 +-------------------------+      +-------------------------+      +-------------------------+
```
