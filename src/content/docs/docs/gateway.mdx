## Role

`conxian-gateway` is the primary strategic middleware repository for institutional integration, routing, aggregation, and compliance verification. It is currently classified as **Beta** with an **Implemented** claim state in the canonical portfolio doctrine.

This page is a technical reference pointer, not a hosted API contract. Use the repository for current interfaces, configuration, release evidence, and deployment instructions.

[Open the `conxian-gateway` repository](https://github.com/Conxian/conxian-gateway)

## Boundary

The gateway is infrastructure for integrations and verification. It does not imply company custody, discretionary control of funds, or a live public banking service. Regulated partners remain responsible for regulated custody and operational controls.
