## Sovereign Protocol Architecture

Conxian provides enterprise-grade, memory-safe software primitives and stateless container images for execution strictly within private cloud environments and physical hardware enclaves (AWS Nitro, Intel SGX, AMD SEV).

## Core Infrastructure Pillars

1. **Bitcoin L1 & L3 Primitives:** Native MuSig2 Schnorr multi-signatures (BIP-340/341/342) and Discrete Log Contracts (DLCs) for trustless financial settlement.
2. **ISO 20022 Legacy Banking:** Native XML message parsers (`pacs.008`, `pacs.009`, `camt.053`) with OData v4 JSON query callback interfaces.
3. **Hardware Enclaves (TEE):** Memory-safe Rust abstractions executing inside isolated hardware enclaves with zero cloud provider runtime trust.
4. **Zero-Knowledge Transparency:** Cryptographic settlement auditability feeds without exposure of underlying financial transaction data.
