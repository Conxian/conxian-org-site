## Strict Domain Firewall Routing

Conxian maintains a strict legal and architectural firewall separating the open-source **Protocol Surface** (`conxian.org`) from the corporate **Operations Surface** (`conxian-labs.com`).

| Component | Target Domain / FQDN | Surface Type | Description |
| :--- | :--- | :--- | :--- |
| **Enclave SDK** | `sdk.conxian.org` | Protocol (`conxian.org`) | Hardware Enclave drivers & MuSig2 signing routines |
| **Banking Gateway** | `gateway.conxian.org` | Protocol (`conxian.org`) | ISO 20022 XML normalizers & OData v4 callbacks |
| **Settlement Engine** | `nexus.conxian.org` | Protocol (`conxian.org`) | Bitcoin L1/L3 DLC contract engine & state solver |
| **Orchestration** | `platform.conxian.org` | Protocol (`conxian.org`) | Sovereign container deployment manifests & runners |
| **Transparency Feed** | `market.conxian.org` | Protocol (`conxian.org`) | Zero-knowledge settlement auditability feeds |
| **B2B Licensing** | `bos.conxian-labs.com` | Corporate (`conxian-labs.com`) | B2B enterprise client portal & license management |
| **Corporate Portal** | `www.conxian-labs.com` | Corporate (`conxian-labs.com`) | Corporate marketing, legal agreements & company news |
