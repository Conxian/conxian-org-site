## Deployment boundary

`conxian.org` is the technical documentation surface. Corporate, legal, and business operations belong to Conxian-Labs surfaces. The repository matrix intentionally links to source repositories rather than asserting that proposed subdomains are deployed.

The legacy `Conxian/Conxian` repository is deprecated and should not be presented as the active protocol implementation. `conxian_market` remains research/experimental and target-state.

## Source of truth

For role, audience, operating label, maturity, claim state, classification, and contradiction disposition, use the [Portfolio Doctrine Register](https://github.com/Conxian/conxian-business/blob/main/docs/PORTFOLIO_DOCTRINE_REGISTER.md). This page is a public navigation view and must not upgrade upstream evidence.

## Boundary invariant

Conxian-Labs is a non-custodial software and infrastructure builder/operator. User keys remain user-controlled; protocol or DAO state remains contract- or governance-defined; regulated partners remain responsible for regulated custody.
